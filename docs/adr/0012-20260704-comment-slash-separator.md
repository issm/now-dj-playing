# ADR-0012: コメントの `/` 区切りは最初のエントリのみ採用

## ステータス

Accepted

## コンテキスト

楽曲ファイルのコメントフィールドに、`/` で区切られた複数の情報が記述されているケースがある。

### 例

```
プリパラ 1st シーズン  INx#12-21,33  #anison #2014q3 #2014q4 #2015q1 #プリパラ #remix / プリパラ 2ndシーズン  OP  #anison #2015q2 #2015q3
```

これは同一楽曲が複数の作品・用途で使用されている場合の記録であり、`/`（前後に空白）で区切られた各エントリがそれぞれ独立した構造を持つ。

## 決定

viewer のコメントパーサー (`commentParser.ts`) では、`/` 区切りの複数エントリのうち**最初のエントリのみ**を解析・表示する。

```typescript
const entry = trimmed.split(/\s+\/\s+/)[0]?.trim();
```

## 理由

- DJ プレイ中の表示としては1つの情報で十分（画面スペースの制約）
- 最初のエントリが「主たる用途」として記述されている前提
- 複数エントリを全て表示すると情報過多になり、視認性が低下する
- パーサーの複雑さを抑えられる

## 将来考慮

- 2つ目以降のエントリも解析して保持し、ユーザー操作で切り替え表示する
- モニタウィンドウ (Issue #2) では全エントリを一覧表示する
