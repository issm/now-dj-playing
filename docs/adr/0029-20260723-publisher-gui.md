# ADR-0029: Publisher GUI アプリ (ndp-publish-gui)

## ステータス

Accepted

## コンテキスト

publisher CLI (`ndp-publish`) は DJ ソフトのフックから自動実行される想定で設計されている。しかし以下のケースでは GUI による手動操作が求められる:

- DJ ソフトがフック機能を持たない環境
- テスト・デモ時に任意の音源ファイルを手動で publish したい
- セッション参加（join）や設定確認を視覚的に行いたい

CLI のコアロジック（タグ抽出、設定ファイル管理、web/local publish）はライブラリクレートとして再利用可能なため、薄い GUI ラッパーとして Tauri アプリを構築する。

## 決定

### アプリ概要

- **パッケージ名**: `ndp-publish-gui`
- **配置**: `apps/publisher-gui/`
- **フレームワーク**: Tauri 2 + React (TypeScript)
- **ウィンドウ**: コンパクト、always on top
- **コア処理**: `apps/publisher` をライブラリクレートとして `path` 依存で参照

### ライブラリクレート化

`apps/publisher` に `[lib]` セクションを追加し、既存モジュールを公開する:

```toml
[lib]
name = "ndp_publish"
path = "src/lib.rs"

[[bin]]
name = "ndp-publish"
path = "src/main.rs"
```

`src/lib.rs` で `pub mod config`, `pub mod tags`, `pub mod local`, `pub mod web` を re-export。CLI (`main.rs`) はライブラリを利用する形にリファクタ。

### UI 構成

コンパクトなシングルウィンドウで以下を縦に配置:

```
┌─────────────────────────────────┐
│ DJ 名: [__________]             │  共通
├─────────────────────────────────┤
│ [web] [local]                   │  モードタブ
├─────────────────────────────────┤
│ (web)                           │
│  エンドポイント: [__________]    │
│  コード: [______] [Join]        │
│                                 │
│ (local)                         │
│  DJ ID: [__________]            │
│  出力先: [__________]           │
├─────────────────────────────────┤
│                                 │
│        ドロップ領域              │  1ファイルのみ受付
│                                 │
├─────────────────────────────────┤
│  ● 成功 / ● 失敗               │  グリーン/レッドのフィードバック
├─────────────────────────────────┤
│ [Config リロード] [Config 保存]  │
└─────────────────────────────────┘
```

### 動作モード

| モード | 動作 |
|---|---|
| web (デフォルト) | ndp-server に HTTP POST で送信 |
| local | ファイルシステムに書き出し |

タブ切り替えで設定 UI が変わる。ドロップ領域は共通。

### 設定ファイル

- `ndp-publish.config.json` を使用（publisher CLI と同一フォーマット）
- ルックアップ最優先: アプリバンドル隣接の `ndp-publish.config.json`
- UI から値を編集し、Config 保存ボタンで書き戻し可能
- Config リロードボタンでファイルから再読み込み

### セッション管理 (web モード)

- セッションファイル: アプリ隣接の `ndp-publish.session.json`
- UI 上のコード入力 + Join ボタンで `POST /api/sessions/join` を実行
- join 成功時にセッションファイルを作成・更新
- publish 時に 401 → 自動再 join（コードが入力済みの場合）

### ドロップ → publish フロー

```
1. ユーザーがファイルを1つドロップ
2. Tauri コマンド呼び出し (ファイルパス + 現在のモード + 設定値)
3. tags::read_tags() でタグ抽出
4. モードに応じて web::publish_web() or local::publish_local()
5. 結果をフロントに返却
6. 成功: グリーン表示 / 失敗: レッド表示 + エラーメッセージ
```

プレビューなし、即時 publish。

### アートワーク (web モード)

publisher CLI と同様、800x800 px にリサイズして Base64 Data URI で送信。

## 理由

- **Tauri 2 採用**: viewer と同じフレームワーク。Rust バックエンドからライブラリクレートを直接呼べる
- **コンパクト + always on top**: DJ アプリが全画面で動作するため、邪魔にならないサイズが必要
- **ライブラリ共有**: CLI と GUI でコアロジックの重複を避ける。バグ修正・機能追加が一箇所で済む
- **即時 publish**: DJ 運用中の手動操作は最小限にしたい。プレビュー確認は不要

## 影響

- `apps/publisher/Cargo.toml` に `[lib]` セクション追加、`src/lib.rs` 新設
- `apps/publisher-gui/` に新規 Tauri プロジェクト追加
- publisher CLI の既存動作に影響なし（`main.rs` がライブラリを呼ぶ形にリファクタするのみ）
