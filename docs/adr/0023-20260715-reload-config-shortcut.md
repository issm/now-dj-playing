# ADR-0023: キーボードショートカットによる設定ファイルの再読み込み

## ステータス

Accepted

## コンテキスト

viewer アプリは起動時に設定ファイル（`development.json` 等）を読み込み、`event_name` や `background_image`、`enable_comments` などの表示設定を反映する。運用中に設定を変更した場合、現状ではアプリを再起動するか、エラー発生時のリロードボタンを使う必要がある。

バックエンドには `reload_config` Tauri コマンドが既に実装されており、フロントエンドにも `handleReloadConfig` 関数が存在するが、正常動作中にユーザーが明示的に呼び出す手段がなかった。

## 決定

### `r` キーで設定を再読み込みする

- メインウィンドウで `r` キーを押すと、設定ファイルの再読み込みと watcher の再起動を行う
- 既存の `handleReloadConfig` を呼び出す（`reload_config` → `applyConfig` → `start_watch`）
- 成功時は上部の info アラートに読み込んだ設定ファイルパスを表示する
- 失敗時は error アラートを表示する（既存動作と同様）

### ショートカット一覧への追加

- `ShortcutOverlay` に「r: 設定ファイルの再読み込み」を追加する
- 一覧の先頭に配置する

## 理由

- `r` キーを選択した理由: "reload" の頭文字であり、他のショートカットと衝突しない
- 新規コマンドを追加しなかった理由: `reload_config` と `handleReloadConfig` が既に存在しており、ショートカットからの呼び出し導線を追加するだけで機能が完成する
- 設定ファイル書き戻し（#28）と独立させた理由: 本件は読み込み方向のみの対応であり、書き込みは別の関心事

## 影響

### フロントエンド (App.tsx)

- キーボードショートカットハンドラの `switch` 文に `case "r"` を追加
- `ShortcutOverlay` の `shortcuts` 配列に項目を追加

### バックエンド

- 変更なし（既存の `reload_config` コマンドをそのまま利用）
