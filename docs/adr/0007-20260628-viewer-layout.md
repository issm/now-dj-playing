# ADR-0007: Viewer レイアウト設計

## ステータス

Accepted

## コンテキスト

iPad 横位置での表示を前提に、楽曲情報を見やすくレイアウトする必要がある。縦位置やウィンドウリサイズにも対応したい。

## 決定

### ヘッダ・ボディ分割

- **ヘッダ (15vh)**: DJ 情報（ロゴ + 名前）をセンタリング
- **ボディ (残り)**: アートワーク + 楽曲情報

### ボディのレイアウト

- **md 以上 (横位置)**: 左半分にアートワーク、右半分に楽曲情報（左揃え）
- **md 未満 (縦位置)**: 縦並び・中央揃えにフォールバック

### レスポンシブ対応

| 要素 | モバイル | md 以上 |
|---|---|---|
| アートワーク | `w-64` (256px 固定) | `w-full` (親幅いっぱい、`max-h-full` + `max-w-[85vh]` で制約) |
| DJ 名 | `text-xl` | `text-3xl` |
| 曲名 | `text-2xl` | `text-4xl` |
| アーティスト | `text-lg` | `text-2xl` |
| アルバム | `text-base` | `text-lg` |

### 楽曲情報の間隔

各項目間は `mt-4` (1rem / 16px) で統一。

### ルートコンテナ

`h-screen` + `overflow-hidden` でビューポート全体を固定高で使用。子要素が `flex-1` / `h-full` で正しく伸びる。

## 理由

- iPad 横位置ではアートワークを大きく見せつつ、楽曲情報も十分な余白を持って表示したい
- `h-screen` を使うことで、スクロールなしの固定表示（デジタルサイネージ的な用途）に適する
- ビューポート相対値 (`vh`) を使うことで、デバイスサイズに自動追従する

## 影響

- スクロール不要の前提のため、情報が多すぎる場合は溢れる可能性がある（現状の表示項目数では問題なし）
