# ADR-0017: コメント領域のタグ表示トグル

## ステータス

Accepted

## コンテキスト

viewer のコメント領域には、楽曲のメタ情報としてタグ（主タグ、年代タグ、属性タグ）が表示される。DJ プレイ中に聴衆向けに表示する際、タグ情報が不要な場面がある。コメントのテキスト部分（source, category）は残しつつ、タグのみを非表示にしたいという要件。

## 決定

### `t` キーによるタグ表示トグル

- メインウィンドウで `t` キーを押すとコメント領域のタグ表示を切り替える
- 対象: 主タグ（`anison` バッジ / `primaryTag`）、年代タグ、属性タグのすべて
- コメントのテキスト部分（source, category）は常に表示する
- モニタウィンドウでは `t` キーは無効

### タグリストのレイアウト変更

- 主タグを独立した行ではなく、タグリスト（`flex-wrap` の `div`）の先頭に配置する
- すべてのタグが同一の `div` に含まれ、`showTags` で一括制御される

### 設定ファイル対応

- `show_tags: boolean` を設定スキーマに追加する
- 起動時のタグ表示の初期状態を制御する
- デフォルト値: `true`（タグを表示する）

```jsonc
{
  "watch_dir": "~/ndp",
  "dj_id": "dj-000",
  "enable_comments": false,
  "show_tags": true
}
```

### ショートカットオーバーレイ

- `?` キーで表示されるショートカット一覧に `t`（タグ表示のトグル）を追加する

## 理由

- `t` キーを採用した理由: "tags" の頭文字で直感的。既存の `c`（comments）と対称的
- 主タグをタグリストに含めた理由: 主タグもメタ情報であり、テキスト内容（source, category）とは性質が異なる。一括で非表示にする方がシンプル
- デフォルト `true` とした理由: タグ情報はコメント表示の一部として有用であり、明示的に隠したい場合のみ `t` キーまたは設定で制御する

## 影響

- `AppConfig` に `showTags` フィールドが追加される
- `CommentDisplay`, `AnisonCommentView`, `GenericCommentView` コンポーネントに `showTags` prop が追加される
- 設定ファイルの example に `show_tags` が追加される
