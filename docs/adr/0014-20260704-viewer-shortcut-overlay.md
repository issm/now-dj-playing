# ADR-0014: `?` キーによるショートカット一覧オーバーレイ

## ステータス

Accepted

## コンテキスト

ADR-0013 で `c` キーによるコメント表示トグルを導入した。今後もキーボードショートカットが増える見込みがあり、利用可能なショートカットをユーザーが確認できる手段が必要になった。

## 決定

### `?` キーでオーバーレイを表示

- `?` キーの押下でショートカット一覧オーバーレイの表示・非表示をトグルする
- `Escape` キーまたは背景クリックでオーバーレイを閉じる
- Vim, Gmail, GitHub 等の慣例に倣い、ヘルプ表示のキーとして `?` を採用

### 実装方針

- `App` コンポーネントに `showShortcuts` state を追加
- 既存のキーイベントリスナーを `switch` 文に統合し、`c` / `?` / `Escape` を一箇所で処理
- `ShortcutOverlay` コンポーネントを新設
  - ショートカット定義を配列で管理し、表示をループで生成
  - `fixed inset-0` + 半透明背景のモーダル形式
  - 背景クリックで閉じる（`stopPropagation` でモーダル内クリックは伝播しない）

### オーバーレイのレイアウト

- 画面中央に `w-80` の角丸カード
- 各ショートカットを「説明 — キー(`kbd`)」の形式で一覧表示
- 背景は `bg-black/80` で暗転

## 理由

- `?` は多くのアプリケーションでヘルプ表示に使われており直感的
- `/` は将来的に検索機能に割り当てる余地を残せる
- ショートカット定義を配列で管理することで、新しいショートカット追加時にデータを追加するだけで一覧に反映される

## 影響

- 新しいキーボードショートカットを追加する際は、キーイベントの `switch` 分岐と `shortcuts` 配列の両方を更新する
- 将来ショートカットが増えた場合、定義を別ファイルに切り出すことを検討する
