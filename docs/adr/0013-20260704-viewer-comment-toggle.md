# ADR-0013: `c` キーによるコメント表示トグル

## ステータス

Accepted

## コンテキスト

ADR-0011 で導入したコメント表示機能は、環境変数 `VITE_ENABLE_COMMENTS` により起動時に表示・非表示が決定されていた。しかし、DJ のプレゼンテーション中に状況に応じてコメント領域を表示・非表示したいケースがある。

## 決定

### キーボードショートカットによるトグル

- `c` キーの押下でコメント領域の表示・非表示をトグルする
- 初期状態は `VITE_ENABLE_COMMENTS` の値に従う
  - `"1"` → 初期表示あり
  - `"0"` または未設定 → 初期表示なし

### 実装方針

- `App` コンポーネントに `showComments` state を追加
- `window` の `keydown` イベントを `useEffect` でリスン
- `TrackDisplay` に `showComments` を props として渡し、表示条件を state ベースに変更

### 環境変数の役割変更

- `VITE_ENABLE_COMMENTS` はコメント表示の「初期値」として機能する
- ランタイムでのトグルが可能になったため、環境変数は起動時のデフォルト値という位置づけになる

## 理由

- プレゼンテーション中にリアルタイムで表示を切り替えたい需要がある
- `c` は "comment" の頭文字であり直感的
- 既存の環境変数による制御を初期値として残すことで、後方互換性を保つ

## 影響

- `VITE_ENABLE_COMMENTS` の意味が「固定の表示制御」から「初期値」に変化する
- 将来 `?` キーによるショートカット一覧表示（issue #12）を追加する際、キーイベント処理の設計基盤となる
